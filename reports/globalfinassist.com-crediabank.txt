## Description
Full-featured phishing-kit-as-a-service impersonating CrediaBank (crediabank.com,
a real Greek bank). Multi-layer bot/analyst-detection front gate (BotBlocker.pro API,
hCaptcha, IP/UA/country/device filtering, one-time-access-per-IP) precedes a
multi-step e-banking clone: login -> password -> card number/expiry/CVV -> one of
SMS/push/email-code OTP (operator's live choice, driven from an admin panel via a
shared SQLite real-time bridge) -> full KYC-grade details (full name, tax ID,
national ID, birth date, email, phone) -> ID-document upload endpoint. A
multi-tenant admin panel ("Z0N51PANEL") with role-based sub-accounts suggests
resale/sub-licensing to multiple operators. Authored/branded by an actor using the
handle Z0N51 (Telegram: @z0n51official, @z0n51pages, @elz0n51).

## Notable architecture
Shared SQLite database (panel/database.db: users/visitors/data tables) as a
real-time message bus between the public lure app and the private admin panel -
lets a human operator watch a victim live and choose (per victim) whether to demand
SMS OTP, push confirmation, or email code, i.e. functionally a live AitM/OTP-relay
tool rather than a static phish. Multi-tenant role-based admin accounts
(role=1 superadmin / role=2 sub-accounts) support resale to multiple operators.
Shipped panel/database.db is EMPTY (0 rows all 3 tables) in this copy - clean
template, no victim PII present. No config.db (Telegram token/SMTP creds/
BotBlocker+hCaptcha keys) shipped in this archive - pre-configuration state.
