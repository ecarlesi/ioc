## Description
Same actor and tooling as the invite-viewer.app campaign (2026-08-31), redeployed on
a freshly-registered open-directory host. Two working VBS droppers
(byte-identical to the original) fetch a ScreenConnect RMM installer disguised as an
event invitation or IRS transcript viewer, silently install it via msiexec, and send
a Telegram-based installation report (system, platform, network/geo-IP, exit code)
before self-deleting. A third VBS variant remains broken/inert (unterminated string
bug, same as originally reported).
