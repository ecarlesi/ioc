## Description

An open directory on a domain impersonating the US FDIC (Federal
Deposit Insurance Corporation) hosts two separate bank-credential
phishing kits targeting First United Bank and Texans Credit Union.
Both are deployments of the SAME commercial/shared "scam-page-as-a-service"
kit framework: every backend PHP file (anti-bot engine, exfiltration
logic, settings schema) is byte-identical between the two copies, and
both hardcode the same license/seller handle (`@psyco_m`). Only the
brand-specific mirrored HTML login pages and outbound message labels
differ.

Multi-step funnel: anti-bot fingerprint gate -> mirrored real bank
login page (username+password) -> the SAME login page shown AGAIN
("double-capture" technique) -> OTP/2FA code entry page -> fake
"success" page that redirects to the real bank site after 6s. Every
captured field is exfiltrated live via Telegram, with victim IP/UA
attached.

**Not yet armed with victim data.** Both kits' logs
(`Settings/Bots-Logs/Bots.txt`, `Settings/Clients-Logs/Clicks.txt`) are
empty — no credentials captured in this snapshot. Delivery domain
registered the day before the crawl (2026-09-17).

Full write-up: Matrix workspace `analysis/fdichelpsupport-bank-phish_20260918/`.

## TTPs

- Cloaking-free but heavily anti-bot-gated funnel: sophisticated
  client+server anti-analysis layer (WebDriver, battery-API laptop
  detection, VR-display-API repurposed as VM/RDP detector, DoNotTrack,
  cookie requirement, hosting-ASN/Tor/VPN IP blocking, blank-UA
  blocking, legacy-Windows-version blocking) gates access before any
  lure page is shown.
- "Double login" capture: identical login form shown twice in a row to
  increase confidence at least one submitted credential pair is
  typo-free, and to generate two separate exfiltration events per
  victim.
- Real online-banking platform mirrored (not hand-built): both login
  pages pull CSS/JS/logo assets live from the bank's actual production
  CDN (Q2 Software "Tecton" engine) rather than re-hosting fake copies
  — visually indistinguishable from the genuine login flow.
- Decoy sitemap.xml (`FakeSitemap.php`) pointing only at an innocuous
  "under construction" placeholder page — anti-scanner camouflage.
- Post-capture redirect to the REAL bank website after a 6-second fake
  "success" page — delays victim suspicion.
- Shared kit framework / licensing model: identical backend and
  hardcoded buyer handle across two unrelated bank-brand deployments —
  consistent with a "scam-page-as-a-service" seller distributing a
  templated kit to (at least) one buyer running multiple brands.

## Cross-kit correlation / forensic note

`First United Bank/processing/done_files/` contains
`truist-logo-188x44.png` and a Truist Bank-branded JS bundle — leftover
artifacts from a scraping tool or shared asset cache previously
pointed at Truist Bank's site, not fully cleaned before this kit was
repackaged under the First United Bank brand. Minor opsec lapse by the
kit builder/seller, not evidence Truist Bank itself is targeted by
this specific deployment.
