## Kit 1 — Home Credit (BNPL impersonation)

### Description
Multi-step credential/OTP harvester impersonating Home Credit Indonesia. Flow: loading splash →
help-center chooser → login (phone + PIN) → 6-digit OTP capture. Exfiltrates via Telegram Bot API
(`sendMessage`, `parse_mode=markdown`) called synchronously from PHP (`curl_exec`) on every step.
Four near-identical copies found, differing only in embedded Telegram bot token/chat_id — same
kit-builder template (`HOME CREDIT.zip` / `HOMECREDIT HYBRID.zip` bundle names).

## Kit 2 — UOB Rewards ("Penukaran-Poin" — points redemption / cashback, bank-card impersonation)

### Description
More aggressive multi-step harvester impersonating UOB Bank's rewards program. Flow: phone number
→ fake points dashboard → cashback percentage slider → **full card details** (PAN, cardholder
name, expiry, CVV) → 6-digit OTP → fake "wrong OTP" retry loop (to catch corrected/second OTP
attempts). Same Telegram exfiltration pattern as Kit 1. Two instances found (`Penukaran-Poin/` and
a byte-identical nested copy `Penukaran-Poin/auobab/` from `auobab.zip`), each with its own
Telegram destination — evidence of the same template resold/reused by (at least) two operators.
