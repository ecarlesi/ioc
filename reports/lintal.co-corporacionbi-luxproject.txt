# IoC Report — lintal.co (corporacionbi / bestado / UniCaja multi-bank phishing bundle)
**Date:** 2026-09-24
**Kits analysed:** three static credential-harvesting kits hosted side by side on the same open directory
**Host:** lintal.co (live mirror of corporacionbi.org)
**Purpose:** Threat-intelligence sharing

---

## Description

A locally-supplied open-directory dump (originally `corporacionbi.org`)
was confirmed still live at **lintal.co** (5.189.153.15, Contabo GmbH,
AS51167, France), serving an identical open-directory listing. The
directory hosts three frontend-only bank-phishing kits cloning:

- **Banco Industrial** (Guatemala) — "BI En Línea" login clone
- **BancoEstado** (Chile) — retail login clone, live credential
  exfiltration (RUT + password sent in clear text via Telegram on
  every form submit)
- **Unicaja Banco** (Spain) — retail login clone, POSTs to a
  `loading.php` backend not present in the dump

Alongside the kits, the same open directory exposes what appears to be
the operator's own **rooted Android phone backup** (Magisk/KernelSU
root-hiding and Play Integrity/SafetyNet spoofing modules — TrickyStore,
PropSpoofer, PlayIntegrityFork — plus the legitimate KernelSU WebUI
Manager APK), two abnormally large padded Windows .NET executables
(likely AV-evasion-via-bloat, payload not extracted), several VBS
scripts (not analysed), and a home-made link-management tool using
free-tier `jsonblob.com`/`allorigins.win`.

Two Telegram bots power the exfiltration/notification channels, both
following a "Lux"-branded naming convention (`LuXAC`/`@luxActivoBot`,
`LuXBot`/`@luxxx066bot`), matching a `luxproject/` directory also
present on the host (currently HTTP 403, contents unknown).

A text file (`1.txt`) contains a `personalpay.dev` deep link matching
the naming convention of a previously tracked Telecom Argentina
"Personal Pay" campaign — actor/tooling overlap flagged but not proven.

Full write-up: Matrix workspace
`analysis/corporacionbi-luxproject-phish_20260924/`.

## TTPs

- Frontend-only credential-harvesting login clones, no shared backend
  framework between the three kits (unlike some "kit-as-a-service"
  bundles seen elsewhere) — each brand has its own bespoke HTML/JS.
- Live client-side Telegram Bot API exfiltration for the BancoEstado
  kit: RUT + password captured directly from the DOM and POSTed in
  clear text on every login-form submit, plus visitor IP/geolocation
  via `ip-api.com`.
- Server-side webhook-based processing for the Banco Industrial/
  UniCaja bots — credential capture happens on the operator's own
  `lintal.co` host rather than purely client-side.
- Multi-step funnel implied but not fully captured in this snapshot:
  the BancoEstado kit redirects to a `verify.html` (likely OTP/2FA
  capture) that was not present in the dump.
- Suspected AV size-heuristic evasion via padded .NET single-file
  executables (36MB/51MB) — payload not extracted, no strings/C2
  recovered.
- Operator's personal rooted-Android backup (root-hiding/Play
  Integrity spoofing tooling) stored on the same open directory as the
  phishing kits — an OPSEC lapse exposing the operator's own device
  posture, not malware aimed at victims.
