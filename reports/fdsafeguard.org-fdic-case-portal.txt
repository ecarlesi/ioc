## Description

Matrix flagged fdsafeguard.org one day after registration as an open directory. The web root exposed the
full kit source (/FDIC.zip), the SQLite database (/database.sqlite), the admin panel (/administration.php)
and the Telegram bot token + chat ID in FDIC/config.php.

The kit is a fake FDIC "case portal": the scammer creates a case, gives the victim a case ID (FDIC-XXXXX) and a
temporary password (Fdic#<date suffix>); the victim logs in, sees a fake account with a balance, transfers,
payees, a card-shipment tracker and a map "pickup" with an authorisation code, then is asked for full name,
date of birth, SSN (the form requires 10 digits), phone, address and a front/back photo of an ID.
The operator drives everything from a Telegram bot (create/edit cases, accounts, activities, resend
credentials, e-mails) and from an admin web panel. It reads as an advance-fee / identity-theft scam; the lure
(e-mail/SMS/phone) was not seen.

State at analysis time: the database had 0 users, 0 cases, 0 uploaded documents (live copy identical to the
dump). No victim PII found. Bot confirmed live on 2026-10-20 (getMe + getWebhookInfo only).

Full write-up: analysis/fdsafeguard-fdic-phish_20261020/ . Blog: carlesi.vg draft 1959.
urlscan: 01a159b9-58e8-708c-a348-f872ccba4d16 (/), 01a159b9-62a0-74f5-9aae-1d17bc6bb881 (/administration.php).
