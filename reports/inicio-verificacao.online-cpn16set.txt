## Description

Brazilian "blocked government balance" advance-fee scam kit impersonating
gov.br/Banco do Brasil. Full PHP+SQLite stack: a cloaking gate (secret
query-string token required to reach the real funnel, else a decoy
"financial diagnosis" page is shown), a React "Gov Auth" CPF
lookup/verification SPA, two embedded Typebot chatbot steps, a fake
6-second "encrypted verification" progress bar, a multi-gateway PIX
checkout (4 interchangeable payment providers), and a 5-stage upsell
chain (fake "IOF tax" charges, one directly impersonating Banco do Brasil
with a real CNPJ number). Every page beacons to an admin/tracking panel
every 6 seconds with session/visitor ID, path, referrer, UA, and — when
present in the URL — the victim's name and CPF.

**Not a bare template.** This copy shipped with real operational data
from an already-run ~41-hour campaign (2026-09-15 to 2026-09-16): 356
distinct victim CPFs, 31,900+ tracking events carrying a victim's full
name, and 13 confirmed real PIX payments collected (~R$936 total) out of
~106 payment attempts. Full write-up: Matrix workspace
`analysis/cpn16set-cpf-scam_20260918/` (victim PII redacted there per
policy; aggregate stats only).

## TTPs

- Cloaking gate: real funnel only renders with a secret query-string
  token present; all other visitors (scanners, casual clicks) see an
  innocuous decoy page — defeats automated content scanners.
- Fake "encrypted verification in progress" progress bar with no real
  check behind it (pure UI theater to build trust before payment).
- Multi-gateway PIX checkout (4 interchangeable providers) designed to
  survive a merchant-account takedown by failing over to the next
  processor.
- Full paid-traffic attribution stack (Facebook CAPI + Pixel, Google Ads,
  UTMify) with live credentials for 3 separate ad accounts already
  configured — a real ad-driven operation, not organic reach.
- `disable-devtool` npm package loaded specifically during the chatbot
  steps to block browser DevTools, hindering manual/analyst inspection.
- Trivial admin-panel auth: hardcoded password plus an undocumented
  GET-parameter bypass left in from development.
- AI-tooling artifact: a leftover screenshot filename referencing OpenAI
  Codex, dated the day before the campaign started, suggests the kit was
  built/iterated with AI coding-assistant help.

## Cross-kit correlation

The BravoPay PIX gateway domain (`bravopay.club`) was already reported in
`reports/cebraspe.cfd.txt` (2026-09-15, unrelated PMAL/CEBRASPE-themed
scam) with a DIFFERENT live merchant API key. Two independently-lured,
unrelated Brazilian PIX-scam kits both configured to use the same gateway
domain, each with its own distinct merchant credentials, is a pattern
worth tracking as a possible bulletproof/complicit-processor signal
across future kit reports.
