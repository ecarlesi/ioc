## Description

Matrix flagged zoom4usinvite.space. Static analysis (125 MB exposed at root +
42 MB backup ZIP left world-readable the day before the crawl) reveals a single
Nigerian-origin threat actor running 9 simultaneous delivery campaigns from two
hosting accounts: zoom4usinvite.space (DigitalOcean) and vistejet.com
(actor-owned cPanel, username "vistejet", Cloudflare-fronted).

Nigerian-origin fingerprint: Zoom kit PHP anti-bot engine explicitly whitelists
MTN, Glo, Airtel, 9mobile while blocking all cloud ASNs; 57 development log
entries all originate from Lagos Nigeria MTN egress IPs (Jul 2025); development
payload name was "PornTube.msi". 5 of 7 embedded Telegram bot tokens confirmed
live at analysis time. No real victim PII found.

Campaigns: (1) Zoom credential phish, (2) Adobe/ClickFix RMM dropper (BAT
double-B64 PS + HTA MR.X V4 GOLD crypter), (3) SSA phish + EXE/cred steal,
(4) VistaJet lure -> EXE, (5) Paperless Post -> FleetDeck RMM agent,
(6) Google AiTM real-time OTP relay (2FA bypass), (7) Gmail Live Panel
(variant of #6 + phone capture), (8) Xfinity/Comcast ATO kit (password +
card + SSN), (9) Adobe/Paperless dual-brand multi-email-provider cred harvest.

Full write-up: analysis/zoom4usinvite-space-dropper_20260921/
