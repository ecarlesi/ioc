# IoC Report — cebraspe.cfd (PMAL fake-concurso PIX scam)
**Date:** 2026-09-15
**Kit analysed:** `pmalagoas` (fake "Concurso Público PM AL 26" — Alagoas
Military Police recruitment exam)
**Purpose:** Threat-intelligence sharing

---

## Description

Brazilian fake public-exam (concurso público) phishing/scam kit
impersonating the Polícia Militar do Estado de Alagoas (PMAL). The
delivery domain itself abuses the CEBRASPE brand (Brazil's real
public-exam board). Collects the victim's CPF, looks up their real
name/date of birth via an illegal third-party API, uses that data in a
fake "identity verification" step to build trust, then extracts money
via TWO sequential fraudulent PIX charges routed through a live
BravoPay merchant account (same API key reused for both charges).

HTML comments left in two legacy pages (`seguro/nascimento/index.html`,
`seguro/verificar/index.html`) show the base template was originally
HTTrack-mirrored from `inss.cadastro-online.com` (fake INSS site,
Apr/May 2025) and later re-skinned for state Military Police brands
(evidence of a PMERJ -> PMESP -> PMAL lineage found in
`.claude/settings.local.json` saved `sed` commands renaming
`Bras_C3_A3o_PMERJ.png` image references).

Registrar: Dynadot Inc (`abuse@dynadot.com`). The 3 `cebraspe*` domains
were registered same-day (2026-09-14); `connect-atacado.store` was
registered 2026-09-10 and shares the fake-TikTok-lure naming pattern
(paired with the unrelated `atacado-connect.store`, note reversed word
order) of a different scam on this same shared IP — but a live HTTP
re-check confirmed it now hosts the identical pmalagoas kit archive,
not the TikTok lure. Name servers: `ns[1-4].dnspro.com.br`.

**Correction note (2026-09-15):** `connect-atacado.store` was initially
excluded from this cluster based on a Smith snapshot that had captured
it as an empty open directory before the kit was deployed there. A
manual live re-check confirmed it now serves the same `pmalagoas.zip`
archive as the other 3 domains — added here as the cluster's 4th
domain.

## TTPs

- Ad-driven landing page (UTMify + Meta Pixel) impersonating a real
  Brazilian state Military Police recruitment exam.
- Reverse "identity verification" trick: kit already knows the victim's
  real name/DOB (fetched server-side from a CPF-lookup API) and asks the
  victim to pick it out of a randomized decoy list, inverting the usual
  trust dynamic of a verification form.
- Double monetization: a primary "registration fee" PIX charge followed
  immediately by a second, independent "verification fee" PIX charge —
  same merchant/API key, different amount/label.
- Multi-brand template reuse (INSS -> PMERJ -> PMESP -> PMAL) evidenced
  by leftover HTTrack mirror comments and saved `sed` asset-rename
  commands in an AI-coding-assistant config file
  (`.claude/settings.local.json`).
